# Imágenes del sitio

`public/og-imagen.png` (1200 × 630, para compartir), `public/apple-touch-icon.png` (180 × 180) y
`public/icono-192.png` / `public/icono-512.png` (manifest, con zona segura para íconos adaptables)
se generaron con Edge a partir de HTML, usando el favicon y las fuentes del repo.

Si cambia la marca, regenerarlas con la misma composición: fondo harina `#faf7f2` con trama de puntos
berenjena, «Moss Taste» en Young Serif, el subtítulo «El recetario de la familia» en berenjena `#6b3a8c`
y la berenjena del favicon a la derecha. Los íconos son el favicon a sangre (sin esquinas redondeadas):
el sistema operativo pone las suyas.
